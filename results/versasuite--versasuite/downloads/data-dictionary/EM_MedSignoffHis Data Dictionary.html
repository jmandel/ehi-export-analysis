EM_MedSignoffHis Data Dictionary

Description of Columns in the Medical Signoff History Table

Original Column Name Expanded Column Name Description
MedSignoffHisID Med Signoff History ID The unique identifier for an entry in the medical signoff history.
AdminHisID Administrative History ID Reference to the associated administrative history record linked to the signoff event.
DateSignoff Date Signoff The date and time when the medical signoff was performed.
PtID Patient Details The unique identifier for the patient whose medical information was signed off.
SignoffType Signoff Type Indicates the type or category of the signoff, such as physician review, nurse verification, etc.
UserID User Details The unique identifier of the user who performed the signoff.
ZUChkSum ZU Checksum A checksum value used for audit logs to verify the integrity of the signoff record.
ZUDate ZU Date The timestamp indicating when the signoff entry was made or last updated in the audit logs.
ZULogonHisID ZULogon History ID A reference to the login history associated with the user who performed the signoff.
