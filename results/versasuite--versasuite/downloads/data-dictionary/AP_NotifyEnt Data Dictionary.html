AP_NotifyEnt Data Dictionary

Detailed Descriptions of Notification Entry Columns for AP_NotifyEnt

Original Column Name Expanded Column Name Description
NotifyEntID Notification Entry ID The unique identifier assigned to each notification event within the system.
AboutRecptID About Recipient ID The identifier pointing to the recipient that the notification is about.
AboutRecptTypeID About Recipient Type ID The type identifier describing the category of recipient the notification is about.
GrpObjID Group Object ID The unique identifier for a set or group of objects related to the notification.
GrpObjTypeFlags Group Object Type Flags Flags representing various attributes of the group object types associated with the notification.
GrpObjTypeID Group Object Type ID The unique identifier that categorizes a group of objects within the notification system.
MacroID Macro ID A unique identifier for a macro or automated sequence used in the notification process.
Message Message Content The content of the notification message conveyed to the recipient.
ObjID Object ID The unique identifier for an individual object that is relevant to the notification.
ObjTypeFlags Object Type Flags Flags indicating specific attributes and characteristics of the object type involved in the notification.
ObjTypeID Object Type ID A unique code defining the particular type of object referenced in the notification.
RecptID Recipient ID The unique identifier for the intended recipient of the notification.
RecptTypeID Recipient Type ID A classification code that specifies the type of recipient for the notification.
StatusID Status ID A unique code representing the status of the notification (e.g., sent, pending, received).
TaskDefID Task Definition ID An identifier for a specific task definition that may be related to the generation or execution of the notification.
ZUChkSum ZU Checksum A checksum used in audit logs for verifying data integrity and tracking changes.
ZUDate ZU Date The date and time at which the entry was last modified, used for audit tracking purposes.
ZULogonHisID ZU Logon History ID The identifier used to track the logon history as part of the notification audit trail.
