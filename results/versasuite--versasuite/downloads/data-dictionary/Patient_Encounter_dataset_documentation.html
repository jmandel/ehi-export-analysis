Documentation for Patient Encounter Dataset

Detailed Descriptions for Each Column

Original Column Name Expanded Column Name Description
PtEncID Patient Encounter Details Unique identifier for each patient encounter.
AdmitClassID Admission Class Details Details of the class of admission, categorizing the nature of the admission.
AdmitTypeID Admission Type Details Type of admission, such as emergency or elective.
CodeDRG Code Diagnosis-Related Group Diagnostic code used for billing and insurance purposes.
CodeMDC Code Major Diagnostic Category Major diagnostic category code for the patient's condition.
DiscDispositionID Discharge Disposition Details Details of the patient's disposition at discharge.
DtFollowup Date Follow-up Scheduled date for the patient's follow-up.
DtFrom Date From Start date of the patient encounter.
DtPtEncStatus Date Patient Encounter Status Date when the status of the patient encounter was updated.
DtTo Date To End date of the patient encounter.
DxSNOMED Diagnosis SNOMED Code Standardized code for the patient's diagnosis.
EmpListID Employee List Details Details of employees involved in the patient's care.
EncNo Encounter Number Number assigned to the patient encounter.
FinancialClassID Financial Class Details Details of the financial class associated with the encounter.
GuarantorRecptID Guarantor Recipient Details Details of the guarantor for the patient's account.
GuarantorRecptTypeID Guarantor Recipient Type Details Type of the guarantor recipient.
GuarantorType Guarantor Type Type of the guarantor, such as an individual or insurance.
HospitalServCodeID Hospital Service Code Details Details of the hospital service code.
Instruction Instruction Instructions given during the patient encounter.
IsDiscInstGiven Is Discharge Instruction Given Indicates if discharge instructions were given.
IsFacilityUsed Is Facility Used Indicates if the healthcare facility was used.
IsFQHC_Claim Is Federally Qualified Health Center Claim Indicates if the claim is related to a Federally Qualified Health Center.
IsMedRecComp Is Medical Record Complete Indicates if the medical record for the encounter is complete.
LengthOfStay Length of Stay The total duration of the patient's stay in the facility.
LenStayActual Length of Stay Actual The actual length of stay, which might differ from the planned duration.
Note Note General notes or observations related to the patient encounter.
Note_CC Note - Chief Complaint Notes specifically addressing the patient's chief complaint.
Note_Discharge Note - Discharge Notes regarding the patient's condition and instructions upon discharge.
Original Column Name Expanded Column Name Description
PrinDxSNOMED Principal Diagnosis SNOMED SNOMED code for the principal diagnosis.
ProcServicePlaceID Procedure Service Place Details Details of the location for procedures and services.
ProcServicePlaceID_DiscTo Procedure Service Place ID - Discharge To Identifier for the discharge location.
ProcServicePlaceID_From Procedure Service Place ID - From Identifier for the original location of the patient.
PrvID_Adm Provider ID - Admission Identifier of the admitting healthcare provider.
PrvID_Att Provider ID - Attending Identifier of the attending healthcare provider.
PrvID_Opr Provider ID - Operator Identifier of the healthcare provider performing operations.
PrvID_Ref Provider ID - Referring Identifier of the referring healthcare provider.
PtAdmitSrcID Patient Admission Source Details Details of the patient's admission source.
PtDischargeStID Patient Discharge Status Details Details of the patient's discharge status.
PtEncIDParent Patient Encounter ID Parent Identifier for the parent patient encounter.
PtEncIDRoot Patient Encounter ID Root Root identifier for the patient encounter.
PtEncSer Patient Encounter Series Indicates if the encounter is part of a series.
PtEncStatusID Patient Encounter Status Details Details of the current encounter status.
PtEncType Patient Encounter Type Type of the patient encounter.
PtID Patient Details Unique identifier for the patient.
PtPolicyID Patient Policy Details Details of the patient's insurance policy.
ReasonGenID Reason General Details General reason for the patient encounter.
ReasonVisit Reason for Visit Specific reason for the patient's visit.
SetupObjType Setup Object Type Type of setup or arrangement for the encounter.
SibOrder Sibling Order Order of the encounter among siblings or related encounters.
SiteID Site Details Identifier for the healthcare facility.
TaskListID Task List Details Details of tasks associated with the encounter.
TempNo Temporary Number A temporary number assigned to the encounter.
UserIDAdmit User ID - Admission Identifier of the user admitting the patient.
ZUChkSum ZU Checksum Checksum value for audit logs.
ZUDate ZU Date Date stamp in audit logs.
ZULogonHisID ZU Logon History Details Identifier for logon history in audit logs.
