Documentation for AP_Ack.csv

Description of AP_Ack Dataset

Original Column Name Expanded Column Name Description
AckID Acknowledgment Identifier A unique identifier for the acknowledgment entry within the dataset.
AckDate Acknowledgment Date The date and time when the acknowledgment was recorded.
ObjID Object Identifier A unique identifier for the object that is being acknowledged.
ObjStatusID Object Status Identifier A reference identifier indicating the current status of the object.
ObjTypeID Object Type Identifier A numerical identifier that represents the type of the object in question.
RecptID Recipient Identifier A unique identifier for the individual or entity that is the recipient of the acknowledgment.
RecptTypeID Recipient Type Identifier An identifier used to classify the type of recipient, such as a patient, healthcare provider, or institution.
ZUChkSum ZU Checksum A cryptographic string used for audit logs to verify the integrity of data at the time of the acknowledgment.
ZUDate ZU Date The date and time stamp for the entry used in the system's audit logs, indicating when the acknowledgment record was created or modified.
ZULogonHisID ZU Logon History Identifier A unique identifier that correlates this acknowledgment entry with a specific logon session within the system's audit logs.
