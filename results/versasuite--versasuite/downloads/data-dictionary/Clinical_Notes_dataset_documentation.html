Documentation for Clinical Notes Dataset

Detailed Descriptions for Each Column

Original Column Name Expanded Column Name Description
CNID CNID Unique identifier for the clinical note.
AmendmentStatus Amendment Status Status of any amendments made to the clinical note.
CNAmendID Clinical Note Amendment Details Details of amendments made to the clinical note.
CosignDate Cosign Date Date when the clinical note was co-signed by another provider.
DateCreated Date Created The date when the clinical note was created.
DateLocked Date Locked The date when the clinical note was locked or finalized.
IsArchived Is Archived Indicates whether the clinical note has been archived.
IsDel Is Deleted Indicates whether the clinical note has been deleted.
NoteX Note X Additional notes or comments related to the clinical note.
NoteGenEntryID Note General Entry Details Details of general entries made in the clinical note.
PrvIDCosign Provider ID - Cosign Identifier of the provider who co-signed the clinical note.
PrvIDSignoff Provider ID - Signoff Identifier of the provider who signed off on the clinical note.
PtEncID Patient Encounter Details Details of the patient encounter associated with the clinical note.
PtID Patient Details Unique identifier for the patient associated with the clinical note.
SignoffDate Signoff Date Date when the clinical note was signed off by the provider.
TransDate Transaction Date Date of the transaction or modification made to the clinical note.
UsedDataTbls Used Data Tables Data tables used or referenced in the clinical note.
ZUChkSum ZU Checksum Checksum value for audit logs, ensuring data integrity.
ZUDate ZU Date Date stamp in audit logs, indicating when the clinical note was last modified.
ZULogonHisID ZU Logon History Details Identifier for logon history in the audit logs, linking user access to the clinical note.
