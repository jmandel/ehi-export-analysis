Application Data for General Note Entries

Original Column Name Expanded Column Name Description
NoteGenEntryID Note Generation Entry Details Unique identifier for each note generation entry, typically used for documentation purposes.
AboutRecptID About Recipient Details Identifier for the recipient that the note is concerning, such as a patient or healthcare provider.
AboutRecptTypeID About Recipient Type Details Classification of the recipient (patient, provider, etc.) that the note is about.
AlertID Alert Details Unique identifier for alerts that are associated with the note, important for critical information sharing.
EncounterNo Encounter Number A numerical identifier for the patient encounter to which the note is related.
GenDate Generation Date The date on which the note was generated or created.
IsCritical Is Critical Indicator of whether the note contains critical information that requires immediate attention.
NoteCatID Note Category Details Identifier for the category of the note, aiding in the classification and organization of notes.
NoteGenEnt Note Generation Entry The entry of the note as generated in the system, including its content and context.
NoteGenID Note Generation Details Unique identifier for the note generation instance, tracking the creation and modifications of the note.
PtEncID Patient Encounter Details Reference to a specific patient encounter associated with the note.
RecptID Recipient Details Identifier for the individual or entity intended to receive or review the note.
RecptTypeID Recipient Type Details Classification of the note's recipient, such as a nurse, doctor, or administrative staff.
UserID User Details Identifier for the user who created or modified the note, typically a healthcare professional or administrative staff.
ZUChkSum ZU Checksum Audit log tracking checksum value for verifying the integrity of the note's data.
ZUDate ZU Date Date indicating when the note was last accessed or modified, used for audit log tracking.
ZULogonHisID ZU Logon History Details Identifier for the history of user logon activities related to the note, important for security and audit purposes.
