Documentation for HC_ProblemHis

Health Care Data for Problem History

Original Column Name Expanded Column Name Description
ProblemHisID Problem History Details Unique identifier for each record in the problem history, detailing the patient's past and current health issues.
ProblemID Problem Details Identifier for a specific health problem, linking to detailed information about the patient's diagnosed condition.
ProblemVeriStatusID Problem Verification Status Details Status identifier indicating the verification level of the problem, such as confirmed, unconfirmed, or pending review.
DateCreated Date Created The date when the problem record was initially created in the system.
DateFrom Date From Start date of the relevance or occurrence of the health problem.
DateOnset Date Onset The date when the symptoms or issues of the problem first appeared or were noticed.
DateTo Date To End date marking the resolution or last noted occurrence of the health problem.
IsEdited Is Edited Indicates whether the problem record has been modified after its initial creation.
IsNoKnown Is No Known Indicates if the patient has no known issues related to the specific health problem category.
LinkedProblemIDs Linked Problem IDs List of identifiers for other health problems that are linked or related to this specific problem.
MDMLocationID_BodySite MDM Location ID - Body Site Identifier for the location on the body where the problem is manifested or most relevant.
NoteGenEntryID Note General Entry Details Identifier for general notes or observations related to the problem, providing additional context or information.
ParentID Parent Details Identifier linking to a broader or parent health issue, under which this specific problem is categorized.
ProblemCtrlID Problem Control Details Control identifier used for managing and tracking the problem record within the system.
ProblemStatusID Problem Status Details Identifier for the current status of the problem, such as active, resolved, or dormant.
ProblemType Problem Type Categorization of the problem based on its nature, such as acute, chronic, or situational.
RecptID Recipient Details Identifier for the recipient of the problem record, typically a healthcare provider or a medical system.
RecptTypeID Recipient Type Details Classification of the recipient, defining the role or type of entity receiving the problem information.
SC_ConceptID SC Concept Details Identifier for the standardized concept related to the problem, facilitating uniform understanding and categorization.
SeverityID Severity Details Classification of the problem's severity, helping in prioritizing care and management.
TargetSiteCode Target Site Code Coded identifier for the specific body site or organ system affected by the problem.
UserID User Details Identifier for the user who entered or last updated the problem record, essential for tracking and accountability.
ZUChkSum ZU Checksum Checksum value used for audit logs to ensure data integrity in the problem history records.
ZUDate ZU Date Date stamp used in audit logs, marking when changes to the problem history were made.
ZULogonHisID ZU Logon History Details Identifier for logon history in the audit logs, linking user access and actions to specific problem history records.
ProblemName Problem Name Descriptive name of the health problem, providing a clear and understandable label for the condition.
ProblemStatusName Problem Status Name Descriptive name for the status of the problem, conveying its current state in the patient's medical history.
SeverityName Severity Name Descriptive name indicating the level of severity of the problem, aiding in clinical assessment and decision-making.
