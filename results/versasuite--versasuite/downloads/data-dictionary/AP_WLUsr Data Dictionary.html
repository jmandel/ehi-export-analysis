AP_WLUsr Data Dictionary

Electronic Health Record (EHR) System - WorkList User Table

Original Column Name Expanded Column Name Description
WLUsrID WorkList User ID The unique identifier assigned to a user within the worklist module of the EHR system.
ActionCompleteID Action Complete ID A reference identifier for a completed action or task associated with the user's worklist.
ActionUsrID Action User ID The identifier for the user who performed or is responsible for an action linked to the worklist.
WLRuleEntID WorkList Rule Entry ID The unique identifier for a specific rule entry that is applied to items in the worklist, often for prioritization or filtering.
ReasonGenID Reason Generation ID The identifier associated with the reason or logic for generating a particular item on the worklist.
RecptID Recipient ID The unique identifier of the recipient for a message, notification, or task within the worklist.
RecptTypeID Recipient Type ID An identifier that categorizes the recipient of a worklist item by type, such as individual healthcare provider, team, or department.
SignedDT Signed Date Time The date and time stamp indicating when a worklist item was signed or authenticated by a user.
SignedUsrID Signed User ID The unique identifier of the user who has authenticated or signed off on a worklist item.
ZUChkSum Audit Check Sum A calculated checksum value used for verifying the integrity of worklist data within audit logs.
ZUDate Audit Date The specific date and time when the worklist data was recorded or entered into the audit log for tracking changes and security purposes.
ZULogonHisID Audit Logon History ID The unique identifier for a logon event within the audit history of the EHR system, used for security and tracking user activity.
