Documentation for Patient Type History Dataset

Detailed Descriptions for Each Column

Original Column Name Expanded Column Name Description
PtTypeHisID Patient Type History Details Unique identifier for each record in the patient type history.
BarrierID Barrier Details Details of barriers faced by the patient, possibly influencing care or treatment.
CampaignEntryID Campaign Entry Details Details of the patient's involvement in health campaigns or programs.
DateEntered Date Entered The date when the record was entered or updated in the patient type history.
NoteX Note X Additional notes or remarks relevant to the patient's type or status.
NoteGenEntryID Note General Entry Details Details of general notes or comments associated with the patient type history.
PtID Patient Details Unique identifier for the patient.
PtTypeID Patient Type Details Details about the type or category of the patient, such as inpatient or outpatient.
UserID User Details Identifier for the user who entered or updated the record.
ZUChkSum ZU Checksum Checksum value for audit logs, ensuring data integrity.
ZUDate ZU Date Date stamp in audit logs, indicating when the record was last modified.
ZULogonHisID ZU Logon History Details Identifier for logon history in the audit logs, linking user access to the patient type history record.
PtTypeName Patient Type Name Descriptive name of the patient type, providing a clearer understanding of the category.
BarrierName Barrier Name Name or description of the barrier faced by the patient.
