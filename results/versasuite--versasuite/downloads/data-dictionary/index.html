Exporting Data with the ehi Export Tool in VersaSuite

The ehi export tool in VersaSuite is designed to export electronic health information (ehi) as a set of files. These files primarily consist of data stored in CSV (Comma-Separated Values) format. Additionally, any information stored in other formats, such as images and documents, will also be included as saved files. The exported files are organized and saved to patient-specific folders within VersaSuite's default export folder.

Key Points to Note:

  1. CSV Data: The primary data exported by the ehi export tool is provided in CSV files. These files contain structured data in a tabular format, making it easy to manipulate and analyze.
  2. Images and Documents: Any information, such as images and documents, associated with patient records will also be exported. These files are included in their original format.
  3. Patient-Specific Folders: Exported data is organized into patient-specific folders. Each patient's data is stored separately within these folders for easy access and management.
  4. Data Dictionary: The documentation accompanying the export tool provides a data dictionary for the tables that may be exported. This dictionary serves as a reference guide, describing the structure and meaning of the exported data fields.
  5. Selective Export: If a particular table does not contain any patient data, it will not be exported. This ensures that only relevant and meaningful information is included in the export.

The ehi export tool in VersaSuite simplifies the process of exporting electronic health information, allowing you to access patient data in a structured and organized manner. Make use of the provided data dictionary to understand the exported data's structure and meaning, ensuring its effective utilization for your needs.
