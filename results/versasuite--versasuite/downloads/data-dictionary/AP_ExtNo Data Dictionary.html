AP_ExtNo Data Dictionary

Detailed Descriptions of AP_ExtNo Table Columns

Original Column Name Expanded Column Name Description
ExtNoID External Number Identifier A unique identifier for the external number associated with a patient or entity in the health record system.
AppearOrder Appearance Order The sequence order in which the external number appears in the patient's record, indicating primary or secondary status.
ExtNo External Number The actual external number assigned to a patient or entity, which may be used for identification or billing purposes.
ExtNoTypeID External Number Type Identifier An identifier matching the external number to its corresponding type, such as insurance number or medical record number.
RecptID Recipient Identifier The identification number of the recipient, who could be a patient or a healthcare entity receiving services or communications.
RecptTypeID Recipient Type Identifier A classification identifier defining the type of recipient, such as individual patient, healthcare provider, or insurance company.
ZUChkSum ZU Check Sum An audit checksum value used to verify the integrity of data within the EHR, specifically for data used in audit logs.
ZUDate ZU Date The date when the record was last accessed or modified, as used in the system's audit logs for tracking purposes.
ZULogonHisID ZU Logon History Identifier An identifier for a logon history entry in the audit logs, indicating when and by whom the system was accessed.
ExtNoTypeName External Number Type Name The descriptive name of the type of external number, such as 'Employee ID', 'Insurance Policy Number', etc.
HierDID Hierarchy Designator Identifier The identifier used to denote the position or role of a patient or entity within an organizational hierarchy.
HierarchyDesignator Hierarchy Designator A descriptor that outlines the level or category within an organizational hierarchy to which the patient or entity belongs.
