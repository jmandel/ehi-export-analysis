EHR Exam Data for Clinical Note Entry

Original Column Name Expanded Column Name Description
CNEntryID Clinical Note Entry Details Unique identifier for each entry within the clinical notes, important for tracking individual notes and their modifications.
CNID Clinical Note Identifier Unique identifier for the clinical note to which this entry belongs, linking the entry to the broader clinical documentation.
DateCreated Date Created The date on which the clinical note entry was created, indicating when the note or observation was documented.
LogonHisID Logon History Details Identifier for the history of user logon activities related to this specific clinical note entry, important for security and auditing.
NoteX Note X Additional notes or comments related to the clinical note entry, providing extra context or information.
PrvID Provider Details Identifier for the healthcare provider who created or is responsible for the clinical note entry.
ReasonGenID Reason Generation Details Identifier for the reason behind generating the clinical note entry, explaining the purpose or trigger for the documentation.
TmplID Template Details Identifier for the template used in creating the clinical note entry, indicating the format or structure of the note.
ZUChkSum ZU Checksum Audit log tracking checksum value, ensuring the integrity and accuracy of the clinical note entry's data.
ZUDate ZU Date Date indicating when the clinical note entry was last accessed or modified, used for audit log tracking.
ZULogonHisID ZU Logon History Details Identifier for the history of user logon activities related to the clinical note entry, for security and audit purposes.
