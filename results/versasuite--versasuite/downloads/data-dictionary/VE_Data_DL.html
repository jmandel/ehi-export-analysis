Documentation for VE_Data_DL.csv

EHR Exam Data for Data Download

Original Column Name Expanded Column Name Description
DataDLID Data Download ID Unique identifier for the data download record, important for tracking data extraction and downloads from the EHR system.
CNEntryID Clinical Note Entry Details Identifier linking the data download to a specific clinical note entry, ensuring traceability of data usage.
ComEntryID Comment Entry Details Identifier for the specific comment entry associated with the data download, potentially for audit or clarification purposes.
DataDL Data Download Indicates the actual data downloaded or extracted from the clinical note or EHR system.
DataFieldID Data Field Details Identifier for specific data fields involved in the download, key for understanding the scope and content of the data extracted.
OldCNEntryID Old Clinical Note Entry Details Reference to previous clinical note entries related to the data download, useful for historical comparison or data integrity checks.
PgEntryID Page Entry Details Identifier for the specific page of documentation from which data was downloaded, important for document tracking and management.
ZUChkSum ZU Checksum Audit log tracking checksum value, used to ensure the integrity and accuracy of the data download's information.
ZUDate ZU Date Date indicating when the data download record was last accessed or modified, used for audit log tracking.
ZULogonHisID ZU Logon History Details Identifier for the history of user logon activities related to the data download, important for security and audit purposes.
DataFieldName Data Field Name Name of the data field involved in the download, providing a clear description of the data type or category.
DataFieldDesc Data Field Description Description of the data field, offering more detailed information about the nature and content of the downloaded data.
