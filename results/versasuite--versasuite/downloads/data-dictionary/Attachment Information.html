Attachment Information

Data Dictionary

Original Column Name Expanded Column Name Description
AttachID Attachment Identifier The unique identifier assigned to an attachment within the EHR system.
DescX Description A detailed textual description of the attachment.
DeviceID Device Identifier The unique identifier of the medical device associated with the attachment.
ImgCatID Image Category Identifier The identifier for the category of the image contained within the attachment.
OrigPathAndFile Original Path and File The original file path and file name where the attachment is stored on the system or network.
RecptID Recipient Identifier The identifier of the individual or entity that is the intended recipient of the attachment.
RecptTypeID Recipient Type Identifier The identifier denoting the type or category of recipient for an attachment.
RelPath Relative Path The relative file path that specifies the location of the attachment within the EHR system.
ZUChkSum ZU Checksum Checksum value used for audit tracking to ensure attachment integrity.
ZUDate ZU Date The date and time stamp for when the attachment was last accessed or modified for audit purposes.
ZULogonHisID ZU Logon History Identifier The identifier for the logon event associated with the user who accessed or modified the attachment, used for audit tracking.
