ComEntryID Comment Entry Details Reference to any comments or notes associated with the image.

OldCNEntryID Old Clinical Note Entry Details Reference to previous clinical note entries associated with the image.
PgEntryID Page Entry Details Identifier for the specific page of documentation related to the image.
CNID Clinical Note Identifier Unique identifier for a clinical note associated with the image.
DataSize Data Size Size of the image data file.

DataTNSize Data Thumbnail Size Size of the thumbnail image data.
DateCreated Date Created The date and time when the image was created or captured.
DeviceID Device Details Identifier for the device used to capture or create the image.

DCMData DICOM Data Data formatted according to the Digital Imaging and Communications in Medicine (DICOM) standard.
DCMInst DICOM Instance Specific instance within a DICOM study, typically referring to an individual image or related set of images.
DCMSeries DICOM Series A series of related images within a DICOM study, usually captured in a single session.
DCMStudy DICOM Study A collection of images and related data representing a complete imaging examination or study.
ImgCatID Image Category Details Identifier for the category to which the image belongs, such as MRI, X-ray, etc.
ImgEditID Image Edit Details Unique identifier for edits or alterations made to the image.
ImgEditTypeID Image Edit Type Details Identifier categorizing the type of edit or alteration made to the image.
ImgFormat Image Format The format in which the image is stored, e.g., JPEG, PNG, DICOM.
ImgName Image Name The name given to the image, often used for easy identification or retrieval.
ImgNote Image Note Any notes or annotations associated with the image.
ImgPath Image Path The file path or location where the image is stored.
ImgTypeID Image Type Details Identifier for the type of image, such as radiograph, ultrasound, etc.
IsArchived Is Archived Indicates whether the image has been archived for long-term storage.
PrvID Provider Details Identifier for the healthcare provider associated with the image.
PXHeight Pixel Height The height of the image in pixels.
PXWidth Pixel Width The width of the image in pixels.
PXXRes Pixel X-Resolution Horizontal resolution of the image in pixels per unit.
PXYRes Pixel Y-Resolution Vertical resolution of the image in pixels per unit.
RecptID Recipient Details Identifier for the individual or entity designated to receive the image or related information.
RecptTypeID Recipient Type Details Classifies the recipient of the image into categories like doctor, patient, etc.
SetImgID Set Image Details Identifier for a set or collection of related images.
SiteID Site Details Identifier for the specific location or site where the image was captured or stored.
ZUChkSum ZU Checksum Audit log tracking checksum value for data integrity verification.
ZUDate ZU Date Audit log tracking date for data access or modification.
ZULogonHisID ZU Logon History Details Identifier for audit log entries related to user logon activities.
