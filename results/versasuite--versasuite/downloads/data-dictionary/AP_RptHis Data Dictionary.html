AP_RptHis Data Dictionary

Audit Report History Data Elements

Original Column Name Expanded Column Name Description
RptHisID Report History Identifier Unique identifier for the report history entry.
AboutRecptID About Recipient Identifier Identifier detailing information about the report's recipient.
AboutRecptTypeID About Recipient Type Identifier Identifier that specifies the type of recipient in relation to the report.
ArchiveID Archive Identifier Unique identifier for the archive where the report or its history is stored.
ContactMethodID Contact Method Identifier Identifier of the method used to contact the recipient of the report.
DateX Date of Entry The date relevant to the report or the entry it is associated with.
DeviceID Device Identifier Identifier for the device from which the report was accessed or generated.
DocType Document Type Classifies the document by type, such as a report, notice, or other official document.
LogonID Logon Identifier Identifier related to the user's logon session when the report was accessed or created.
NoteX Note Text Any relevant notes or comments associated with the report entry.
RecptID Recipient Identifier Unique identifier for the individual or entity who is the recipient of the report.
RecptTypeID Recipient Type Identifier Identifier representing the recipient's categorization such as patient, provider, or staff.
RptHisPath Report History File Path The file system path that indicates where the report history is stored.
RptID Report Identifier Unique identifier assigned to the report for tracking and reference.
ZUChkSum Audit Check Sum Checksum used to validate the integrity of the data in the audit report.
ZUDate Audit Date The date on which the audit event was recorded.
ZULogonHisID Audit Logon History Identifier Record identifier for tracking the history of user logons for security and audit purposes.
