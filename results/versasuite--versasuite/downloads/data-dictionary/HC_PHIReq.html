Documentation for HC_PHIReq.csv

Health Care Data for Protected Health Information Requests

Original Column Name Expanded Column Name Description
PHIReqID PHI Request Details Unique identifier for each Protected Health Information request, crucial for tracking and managing PHI access and dissemination.
CNEntryID Clinical Note Entry Details Identifier linking the PHI request to a specific clinical note entry.
CNID Clinical Note Identifier Unique identifier for a clinical note associated with the PHI request.
ContactMethodID Contact Method Details Identifier for the method of contact used in the PHI request, such as email, phone, or postal mail.
DateReq Date Requested The date on which the PHI request was made.
InfoID Information Details Unique identifier for the specific information being requested in the PHI request.
InfoTypeID Information Type Details Identifier for the type of information requested, such as medical history, lab results, etc.
IsActive Is Active Indicates whether the PHI request is currently active or has been closed.
IsActiveDate Is Active Date The date on which the PHI request was marked as active or inactive.
IsSent Is Sent Indicates whether the requested PHI has been sent to the requester.
NoteX Note X General note or comment field related to the PHI request, for additional observations or information.
PHIDiscReasonID PHI Disclosure Reason Details Identifier for the reason behind the disclosure of PHI, important for compliance and tracking purposes.
PtEncID Patient Encounter Details Reference to a specific patient encounter associated with the PHI request.
PtID Patient Details Unique identifier for the patient whose PHI is being requested.
RecptID Recipient Details Identifier for the individual or entity intended to receive the requested PHI.
RecptTypeID Recipient Type Details Classification of the PHI request's recipient, such as a healthcare provider, insurance company, or patient.
RefID Reference Details Identifier for additional references or related documents linked to the PHI request.
RequestingUserID Requesting User Details Identifier for the user who initiated the PHI request, typically a healthcare professional or administrative staff.
TaskListID Task List Details Identifier for a list of tasks or actions associated with the processing of the PHI request.
ZUChkSum ZU Checksum Audit log tracking checksum value, ensuring the integrity and accuracy of the PHI request data.
ZUDate ZU Date Date indicating when the PHI request record was last accessed or modified, used for audit log tracking.
ZULogonHisID ZU Logon History Details Identifier for the history of user logon activities related to the PHI request, for security and audit purposes.
PHIReq_ContactMethodName PHI Request Contact Method Name Name describing the contact method used in the PHI request, such as 'Email', 'Phone', etc.
PHIReq_RecptTypeName PHI Request Recipient Type Name Name indicating the type of recipient for the PHI request.
PHIReq_ReasonName PHI Request Reason Name Name describing the reason for the PHI request, such as 'Treatment', 'Payment', 'Healthcare Operations', etc.
PatName Patient Name Full name of the patient whose PHI is being requested.
PHIRecpt_PHIReceiptID PHI Receipt PHI Receipt Details Unique identifier for the receipt record of the requested PHI, tracking its delivery and acknowledgment.
PHIRecpt_ContactMethodID PHI Receipt Contact Method Details Identifier for the contact method used for the receipt of PHI, such as email or postal mail.
PHIRecpt_ContOfCareID PHI Receipt Continuity of Care Details Identifier linking the PHI receipt to a specific continuity of care record.
PHIRecpt_DateReceived PHI Receipt Date Received The date on which the PHI was received by the intended recipient.
PHIRecpt_UserID_RcvBy PHI Receipt User ID Received By Identifier for the user who received the PHI, confirming its delivery and receipt.
PHIRecpt_IsActive PHI Receipt Is Active Indicates whether the record of the PHI receipt is currently active or has been closed.
PHIRecpt_IsActiveDate PHI Receipt Is Active Date The date on which the record of the PHI receipt was marked as active or inactive.
PHIRecpt_IsIncorporated PHI Receipt Is Incorporated Indicates whether the received PHI has been incorporated into the patient's official health record.
PHIRecpt_Note PHI Receipt Note Additional notes or comments related to the receipt of PHI.
PHIRecpt_ReqStatusID PHI Receipt Request Status Details Identifier for the current status of the PHI request, such as 'Pending', 'Completed', or 'Rejected'.
UserName User Name Name of the user who initiated or is managing the PHI request.
