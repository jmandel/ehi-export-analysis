AP_PhoneEntryHis Data Dictionary

Data definitions for the Phone Entry History in an Electronic Health Record (EHR) system

Original Column Name Expanded Column Name Description
PatName Patient Name The full legal name of the patient whose phone entry is being recorded.
PhoneEntryHisID Phone Entry History ID The unique identifier for each phone entry within the patient's history.
AppearOrder Appearance Order The ordinal position indicating the chronological order of the phone entries.
CountryID Country ID The identifier representing the country associated with the phone number.
DateFrom Date From The commencement date indicating when the particular phone number became associated with the patient.
DateInact Date Inactive The date on which the phone number was recorded as no longer in use by the patient.
DateTo Date To The termination date after which the phone number is no longer associated with the patient.
LocalSiteIDs Local Site IDs Identifiers for the healthcare facility sites that are relevant to the patient's phone entries.
PhoneEquipmentTypeID Phone Equipment Type ID A categorical identifier indicating the type of phone equipment used.
PhoneTypeID Phone Type ID An identifier for the type of phone service (e.g., mobile, landline) documented in the entry.
PhoneUseTypeID Phone Use Type ID An identifier classifying the intended use of the phone (e.g., personal, business).
RecptID Recipient ID The unique identifier of the recipient (individual or entity) of the phone communication.
RecptTypeID Recipient Type ID An ID that categorizes the type of recipient of the communication (e.g., patient, healthcare provider, insurance company).
TextNo Text Number A distinct number assigned to text messages related to the patient's phone record.
TextNoNote Text Number Note Additional remarks or clarifications regarding the Text Number.
ZUChkSum ZU Check Sum An algorithmically generated number used to verify the integrity of data for audit purposes.
ZUDate ZU Date The timestamp recorded in the audit log reflecting the last update or change to the record.
ZULogonHisID ZULogon History ID A unique identifier for the login session history related to changes in the phone entry record.
PhoneTypeName Phone Type Name The descriptive name of the type of phone service associated with the entry.
CountryName Country Name The full name of the country associated with the phone number entry.
