IsViewAttempt Is View Attempt Tracks attempts to view the security profile by the recipient or other users.
NoteX Note Any additional notes or comments related to the security profile recipient.

RecptTypeID Recipient Type ID The categorization ID indicating the type of recipient for security profile purposes.

ZUDate ZU Date The date when the latest change was recorded in the security profile audit log.
