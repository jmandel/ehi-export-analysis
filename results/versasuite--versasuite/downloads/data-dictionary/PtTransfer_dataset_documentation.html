Documentation for Patient Transfer Dataset

Detailed Descriptions for Each Column

Original Column Name Expanded Column Name Description
PtTransferID Patient Transfer Details Unique identifier for each patient transfer record.
CNID Clinical Note ID Identifier for the clinical note associated with the transfer.
CNEntryID Clinical Note Entry Details Details of the specific entry in the clinical note related to the transfer.
DateTransfer Date Transfer The date when the patient transfer occurred.
DtToAssign Date To Assign The date when the patient was assigned to the transfer.
DtToCurr Date To Current The current date related to the transfer process.
DtToUser Date To User The date when the user processed or handled the transfer.
LocID_From Location ID - From Identifier for the location from where the patient is being transferred.
LocID_To Location ID - To Identifier for the destination location to which the patient is being transferred.
PtEncID Patient Encounter Details Details of the patient encounter associated with the transfer.
PtID Patient Details Unique identifier for the patient being transferred.
Reason Reason The reason for the patient's transfer.
SiteID Site Details Identifier for the healthcare facility or site involved in the transfer.
TransferType Transfer Type The type of patient transfer, such as intra-hospital or inter-hospital.
UserID_Escort User ID - Escort Identifier of the user or staff member who escorted the patient during the transfer.
UserID_From User ID - From Identifier of the user or staff member from the originating location of the transfer.
UserID_To User ID - To Identifier of the user or staff member at the destination location of the transfer.
ZUChkSum ZU Checksum Checksum value for audit logs, ensuring data integrity.
ZUDate ZU Date Date stamp in audit logs, indicating when the transfer record was last modified.
ZULogonHisID ZU Logon History Details Identifier for logon history in the audit logs, linking user access to the transfer record.
