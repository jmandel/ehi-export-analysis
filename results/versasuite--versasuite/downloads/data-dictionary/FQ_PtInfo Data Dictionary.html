FQ_PtInfo Data Dictionary

Detailed Descriptions of Patient Information Fields

Original Column Name Expanded Column Name Description
PtInfoID Patient Information Details A unique identifier assigned to each set of patient information details for reference within the healthcare management system.
AgWorkerID Agricultural Worker Details A unique identifier for patient records that contain specific details about an agricultural worker's employment and related health information.
HomelessID Homeless Details A unique identifier for capturing details relevant to a patient's homelessness status, including health implications and care considerations.
IsDisabled Is Disabled A binary indicator (e.g., Yes/No) detailing whether the patient has a disability, impacting treatment plans and accessibility requirements.
PtID Patient Details The unique identifier for a patient's personal and demographic details within the health record system.
VeteranID Veteran Details An identifier relevant to a patient who has served in the military, providing access to veteran-specific health resources and care programs.
ZUChkSum Audit Checksum Checksum value used to verify data integrity for auditing purposes, ensuring no unauthorized changes have been made to the patient's information.
ZUDate Audit Date The date and time stamp for when the patient's record was accessed or modified, for maintaining a secure and accurate audit trail.
ZULogonHisID User Logon History Details A record ID that captures the history of user logon activity for secure tracking of access to this specific patient's information.
AgWorkerName Agricultural Worker Name The complete name of the agricultural worker referenced in the patient's details, if applicable.
HomelessName Homeless Name The label or category name associated with a patient's homelessness status, used for classification and resource allocation purposes.
VeteranName Veteran Name The name of the veteran as recorded in the patient details, which may be used to connect the patient with veteran-specific services.
