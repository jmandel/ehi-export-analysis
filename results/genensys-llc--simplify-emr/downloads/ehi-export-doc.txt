Simplify EMR
Export Format
________________


All Patient Mode


1. Zip File Naming Convention: Patient_export_{date}.zip
   1. Each Patient with a  folder with the single format (as described below) 
Single Patient Mode


1. Folder with the naming convention Lastname_FirstName_patientId_Date
   1. Folder Contains
      1. Lastname_FirstName_ccda.xml 
         1. CCDA File Conformant to USCDI v1. Please Refer to USCDI-Version-1-July-2020-Errata-Final_0.pdf for CCDA Specifications
      2. Sub Folders
         1. Encounters - All Visit Notes in PDF or HTML Format (0 to many)
            1. {encounterId}_{date}.pdf or {encounterId}_{date}.html
         2. Patient Documents - Other Documents in PDF Format  or HTML Format  (0 to many)
            1. {documentId}_{date}.pdf or {documentId}_{date}.html
