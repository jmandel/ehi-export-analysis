About MedNet's emr4MD Product

emr4MD, version 9.10 is ONC Certified HIT solution is dynamic web-based EHR software, part of MedNet Medical Solutions' affordable EMR/EHR and Medical Billing solution, which integrates your administrative and clinical processes on one system for streamlined, consistent patient care. We customize your templates to meet your clinical needs and assist the physician with efficient documentation. We feel that EMR should not only be a tool for “meaningful” documentation, but help us in pro-actively providing disease management at the point of service. Thus we built a robust “Disease Management Engine”.

API Syntax

The API is a read-only RESTful FHIR® STU 3 Ballot API and follows the syntax described at http://hl7.org/fhir/2016Sep/http.html .
All data access requests will be in the following format, in which the [base] URL will need to be obtained from the Data Holder, either directly or via directory information: GET [base]/[resource-specific parameters]…
