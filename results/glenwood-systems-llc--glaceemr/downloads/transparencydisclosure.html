    Pricing Transparency

     

    GlaceEMR is offered as a based cloud certified EHR application available for a single low monthly fee per provider and a onetime implementation fee. There are no additional charges for non-billing support staff. GlaceEMR includes clinical documentation modules, eRX, patient portal, hosting, maintenance and upgrades, Glenwood standard lab interface programing, and integrated scheduler. Third party patient educational handout material (170.315(a)(13) Patient-specific education resources), Direct Trust secure data exchange (170.315(b)(1) Transitions of care - create and transmit transition of care/referral summaries), Wolters Kluwer UpToDate via InfoButton (Clinical Decision Support - 170.315(a)(9)), reporting registry and EPCS validation are available at an additional cost.

     

    GlacePremium and GlaceComplete are RCM / billing services offered by Glenwood. Each of these is offered based on a percentage of total collected revenue model and include the all components of GlaceEMR and clearinghouse at no additional charge. The monthly fee for each of these is the greater of a set percentage of total collections or a monthly minimum per provider.

    EHI Data Export


    Electronic Health Information (EHI) export will enable a clinician to export all EHI of a single patient or population of patients or all their patients stored in the GlaceEMR.


    Single Patient Export


    Enable a user to create an export file with all the EHI of a single patient stored in GlaceEMR. Single Patient EHI Export includes an authorized user's ability to execute a single patient export and download the zip file containing all the EHI of this exported patient.


    Patient Population Export


    Enable a user to create an export file with all the EHI belonging to a selected group of patients or the entire patient population that is stored in GlaceEMR. Patient Population EHI Export includes the capability for an authorized user to either specify criteria to select a population of patients or all the patients in the database to export and download the zip file containing all the EHI of these exported patients.


    GlaceEMR provides EHI exports for patients as a ZIP file containing various folders and files. ZIP files can be opened and extracted using a variety of free products (Windows File Explorer, 7-Zip, etc.).


    Zip Contains CSV, HTML, PDF, JPG, PNG, XML, etc. file types.
