Introduction
Electronic Health Information (EHI) export will enable a clinician to export all EHI of a single patient or
population of patients or all their patients stored in the GlaceEMR.
EHI means “electronic protected health information” (ePHI) as defined in 45 CFR 160.103 to the extent
that it would be included in a designated record set as defined in 45 CFR 164.501, regardless of whether
the group of records are used or maintained by or for the practice.

Single Patient Export
Enable a user to timely create an export file with all the EHI of a single patient that are stored in
GlaceEMR. Single Patient EHI Export includes the capability for an authorized user to execute a single
patient export and download the zip file contain all the EHI of this exported patient.

Patient Population Export
Enable a user to timely create an export file with all the EHI belong to a selected group of patients or
entire patient population that are stored in GlaceEMR. Patient Population EHI Export includes the
capability for an authorized user to either to specify a criteria to select a population of patients or all the
patients in the database to export and download the zip file contain all the EHI of this exported patients.

Documents Folder Content
Which contains patient related documents in HTML, PDF and XML format.
The main Document folder contains one sub-folder for each patient named in the following format
LastName,FirstName-(DOB MM-DD-YYYY)-(Account#)-[PatientID]
Ex: SMITH,JOHN-(03-15-1983)-(1234F2)-[412]
This sub-folder contains.
1. Clinical Templates Files: Exported as HTML and PDF formats. HTML files are kept under HTML folder
and PDF files are kept under PDF folder.
These are indexed in EMR/Clinical_Document_Index_File.csv
The Files are named as follows:
HTML/LastName,FirstName-(DOB MM-DD-YYYY)-(Account#)-[PatientID]-[NoteID]-Notes Document
Name.html
Ex: HTML/SMITH, JOHN-(03-15-1983)-(1234F2)-[412]-[43422]-Progress Notes.html
PDF/LastName,FirstName-(DOB MM-DD-YYYY)-(Account#)-[PatientID]-[NoteID]-Notes Document
Name.pdf
Ex: PDF/SMITH, JOHN-(03-15-1983)-(1234F2)-[412]-[43422]-Progress Notes.pdf
2. Scanned Documents and Attached Documents: Scanned Documents are exported in PNG or JPEG
format in which they are stored in the GlaceEMR. Attached Documents are exported in the format
they are originally attached to GlaceEMR.
These are indexed in EMR/Scan_And_Attachments_Index_File.csv
The Files are named as follows:
LastName,FirstName-(DOB MM-DD-YYYY)-(Account#)-[PatientID]-[DocumentID]-(Created Date MMDD-YYYY)-DocumentCategory.jpg
Ex: SMITH,JOHN-(03-15-1983)-(1234F2)-[412]-[139418]-(10-06-2023)-Adv-Directive Mental Health
Treatment.jpg
