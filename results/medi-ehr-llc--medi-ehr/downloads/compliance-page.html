Compliance

I. Electronic Health Information Export

  1. Single Patient Export
    Medi-EHR allows a user to export electronic health information (EHI) for a single patient at any time without developer assistance using the following standardized file formats explained below
  2. Multi-Patient Export
    Medi-EHR can export all the data for a patient population in our standardized format explained below
  3. File Formats
    These are standardized formats. Medi-EHR updates all formats on a quarterly schedule unless otherwise indicated. If a specific update or patch is released about one of these formats, then an on-demand update is made.
    1. CSV
      A comma-separated values (CSV) file is a delimited text file that uses a comma to separate values. Each line of the file is a data record. Each record consists of one or more fields, separated by commas. The use of the comma as a field separator is the source of the name for this file format.
    2. HTML
      The HyperText Markup Language, or HTML, is the standard markup language for documents designed to be displayed in a web browser.
