Object:

This document describes how QSmartCare’s EHR enables the user to export the patient’s EHI data for a single patient or for all the patients. This functionality can be performed by the Author personnel only. This document covers how the user can export single and multiple patient electronic health information.

Scope:

The main scope is to focus on details on the exporting of patient electronic health information in a computable and human-readable format.

 

Login of QSC

Type the URL https://www.qsmartcare.com/app/index.html and click the enter button. The
Login page appears below.

 

 

• Enter Username & Password

• Click the Login

 

 

· PIN validation appears.

· Enter PIN and click submit.

 

 

·         Once logged in to the application, the page navigates to the Dashboard page.

 

 

 

Single Patient Export:

 

• Navigate to Patient > CCDA > Export as shown below.

 

 

• Click on the icon EHI data PDF to export the patient data in PDF (Human readable format)

Multiple Patient Export:

 

• Navigate to Patient > CCDA > Export as shown below.

 

 

• Select the patients by clicking the check box on the left side.

 

 

• Upon clicking the check box EHI data PDF icon will be displayed.

 

 

·         Click the icon EHI data PDF icon.

 

 

·         All the selected patient’s data will be displayed as a Zipped folder.

 

 

·         User can click on the folder and view the respective patient EHI data.

 

 

 

·         Click on the icon EHI data Json to export the patient data in Computable format (Json format)

 

·         Upon clicking the icon EHI data Json patient’s EHI data will be displayed as a zip folder.

 

 

 

 

·          User can click on the folder and view the respective patient EHI data.
