Resource Profile: Profile - Athena ClinicalImpression

Official URL: https://docs.mydata.athenahealth.com/fhir-r4/StructureDefinition-athena-clinicalimpressn-profile.html Version: 25.0.0
Active as of 2022-03-01 Computable Name: AthenaClinicalImpression

athena clinicalimpression profile

This ClinicalImpression profile is part of the set of resource profiles supported by the API Server used with the athenaPractice and athenaFlow products. It further describes read and search capabilities of these products. Note: The create and update operations are NOT supported for this resource.

Overview

A record of a clinical assessment performed to determine what problem(s) may affect the patient and before planning the treatments or management strategies that are best to manage a patient's condition

Scope and Usage

This profile is used to define the content that will be returned by the API Server in response to requests to access ClinicalImpression resources. All elements listed in the differential profile view are Supported, which means that the API Server is capable of supplying these fields from the product database when they have been populated via the product or its APIs.

Source

The ClinicalImpression resource is a record of a clinical assessment performed to determine what problem(s) may affect the patient and before planning the treatments or management strategies that are best to manage a patient's condition. It is derived from the ASSESS table in athenaPractice and in athenaFlow. Specific detail can be found in the Mappings tab in the profile detail page.
