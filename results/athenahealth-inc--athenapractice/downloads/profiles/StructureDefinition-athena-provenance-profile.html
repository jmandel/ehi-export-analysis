Resource Profile: Profile - Athena Provenance

Official URL: https://docs.mydata.athenahealth.com/fhir-r4/StructureDefinition-athena-provenance-profile.html Version: 25.0.0
Active as of 2022-03-01 Computable Name: AthenaProvenance

Defines constraints and extensions on the Provenance resource as supported by Athena Products.

This Provenance profile is part of the set of resource profiles supported by the API Server used with the athenaPractice and athenaFlow products. It further describes read and search capabilities of these products. Note: The create and update operations are NOT supported for this resource.

Overview

The Provenance resource tracks information about the activity that created, revised, deleted, or signed a version of a resource, describing the entities and agents involved.

Scope and Usage

This profile is used to define the content that will be returned by the API Server in response to requests to access Provenance resources. All elements listed in the differential profile view are Supported, which means that the API Server is capable of supplying these fields from the product database when they have been populated via the product or its APIs.

Source

The Provenance resource gives information about who modified target resources and when they were modified. It is derived from the appropriate fields in many database tables in the athenaPractice and athenaFlow products. Multiple fields are used in the various scenarios that create, update, and sign data. Specific detail can be found in the Mappings tab in the profile detail page.
