Logical Model: Profile - Athena Custom PatientInsurance

Official URL: https://docs.mydata.athenahealth.com/fhir-r4/StructureDefinition-athena-patientInsurance-profile.html Version: 25.0.0
Active as of 2023-03-01 Computable Name: PatientInsurance

The patientInsurance describes a health insurance offering comprised of a list of covered benefits (i.e. the product), costs associated with those benefits (i.e. the plan), and additional information about the offering, such as who it is owned and administered by, a coverage area, contact information, etc..


This custom PatientInsurance is part of the set of resource profiles supported by the API Server used with the athenaPractice 23.0.0. This is not a FHIR Conformant Resource. It further describes read and search capabilities of these products.
Note: Create and Update operations are NOT supported for this resource.

Overview

A financial tool for tracking value accrued for a particular purpose. In the healthcare field, used to track insurance for a patient, guarantor details and etc

Scope and Usage

PatientInsurance describes a health insurance offering comprised of a list of covered benefits (i.e. the product), costs associated with those benefits (i.e. the plan), and additional inform action about the offering, such as who it is owned and administered by, a coverage area, patient contact information, etc. All elements listed in the differential profile view are Supported, which means that the API Server is capable of supplying these fields from the product database when they have been populated via the product or its APIs.

Source

PatientInsurance resource contains information about insurance plan/product associated with the patient and guarantor information. This information is extracted from Guarantor, PatientProfile, InsuranceCarriers, InsuranceGroup, Doctorfacility tables.
