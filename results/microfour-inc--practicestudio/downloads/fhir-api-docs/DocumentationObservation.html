Terminology Bindings

Terminology Detail
Observation.category A code that classifies the general type of observation being made.
Observation.code Describes what was observed. Sometimes this is called the observation "name".
Observation.component Some observations have multiple component observations.

Parameters

Parameter Is Required Description
Id This, or patient. The logical resource ID associated with the resource.
patient This plus code, or ID The patient who has the immunization.
code This plus patient The observations code. Example: code=72166-2
category This plus patient The observations report's category
date No Date range into which the observation falls. Example: date=gt2014-09-24
_revinclude No A request to include any Provenance resource in the bundle.
