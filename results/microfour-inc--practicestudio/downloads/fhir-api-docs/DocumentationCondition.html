Terminology Bindings

Terminology Detail
Condition.clinicalStatus The clinical status of the condition.
Condition.verificationStatus The verification status to support the clinical status of the condition.
Condition.category A category assigned to the condition.
Condition.code Identification of the condition, problem or diagnosis.

Parameters

Parameter Is Required Description
Id This, or patient. The logical resource ID associated with the resource.
Patient This, or ID The patient who has the condition.
_revinclude No A request to include any Provenance resource in the bundle.
