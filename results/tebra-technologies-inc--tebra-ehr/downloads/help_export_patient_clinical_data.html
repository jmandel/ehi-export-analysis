Export Patient Clinical Data

  1. Last updated
  2. Save as PDF
  1. Access Export Patient Data
  2. Run One-time Export
  3. Run Recurring Export
  4. Download Export
Updated: 12/19/2025 | Views: 48611

Tebra has the ability to export patient clinical data in bulk. The patient clinical data exports as individual XML Summary of Care files for patients with clinical notes created, signed, co-signed, or assigned by/to the selected provider during the timeframe specified. In addition to the Summary of Care file, the export also includes patients documents.

Access Export Patient Data

  1. Hover over the User icon and click on Practice Settings. The Practice Settings page opens.
  2. Click Data Management. Additional setting options expands.
  3. Click Export Patient Data. The Export Patient Summaries page opens displaying one-time exports and recurring exports from the last 60 days.

Run One-time Export

  1. Click Run Export. The Run Export pop-up window opens.
  2. Date range: Select a date range to include patients based on when they were seen by the provider.
  3. Provider: Select all providers or a specific provider from the drop-down to include in the export.
  4. Export Date: Select when to run the export.
    • Now: Click to select "Now" to generate the export now.
    • Date Range: Click to select the date range option. Then, select the date and time to generate the export.
  5. Click Run Export. The requested export displays under the Patient Summaries list with the status of Pending.

Run Recurring Export

  1. Click Run Export. The Run Export pop-up window opens.
  2. Click Recurring. The recurring options displays.
  3. Select the export frequency:
    • Monthly: Click to select "Monthly" to generate exports on the first day of every month.
    • Weekly: Click to select "Weekly" to generate exports every Monday.
  4. Provider: Select all providers or a specific provider from the drop-down to include in the export.
  5. Click Run Export. The requested export displays under the Manage Recurring Exports list.
    Note: To delete a recurring export, click the trash icon next to export under Manage Recurring Exports.

Download Export

Once the export is ready, the status changes to Ready and the user who initiated the export receives a notification via the Message Center.

  1. Click the download icon to save the zip file.
  2. Open the saved zip file to access the patients .xml Summary of Care files.
