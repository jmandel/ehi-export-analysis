Real World Testing Plan 2025

Date: Oct. 30, 2024
Product/Service: PARADIGM 22
 

Real World Testing is an annual requirement outlined in the ONC 21st Century Cures Act Final Rule for all Health IT Developers participating in the ONC Health IT Certification Program. The purpose of this Condition and Maintenance of Certification requirement is for Health IT Developers to demonstrate interoperability and functionality of their Certified Health IT in real world settings and scenarios, rather than in a controlled test environment with an ONC-Authorized Testing Lab. Real World Testing verifies that deployed Certified Health IT continues to perform as intended by conducting and measuring observations of interoperability and data exchange. These observations are described in a public and transparent way through Real World Testing plans and reported as Real World Testing results.

PARADIGM EHI Export Documentation

Date: Sept. 26, 2023
Product/Service: PARADIGM 22
 

The PARADIGM® FHIR Data Portability module provides authorized EHR users the ability to export the Electronic Health Information (EHI) of a patient or set of patients. The Electronic Health Information (EHI) is exported in C-CDA and JSON formats. This document provides guidance on the usage of the PARADIGM® FHIR Data Portability module.

PARADIGM Patient API

Date: Dec. 16, 2022
Product/Service: PARADIGM 22 
 

The PARADIGM® Patient API provides resources for patient searches to retrieve internal unique identifiers to be used to retrieve data through the PARADIGM® Patient API as a C-CDA or through the PARADIGM® FHIR API set of resources. PARADIGM FHIR API

Date: Dec. 9, 2022
Product/Service: PARADIGM 22 
 

The PARADIGM® FHIR API provides thorough REST-based interoperability of patient health information to developers and software using the HL7® FHIR® standard and the U.S. Core Data for Interoperability (USCDI) data classes and data elements. The document provides guidance on the usage of the PARADIGM® FHIR API.
