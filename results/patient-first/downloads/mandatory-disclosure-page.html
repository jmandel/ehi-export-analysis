Electronic Health Information (EHI) Export

EHI Export functionality allows health systems to do a manual one-time export of health data. The export contains the electronic health information available in a patient's record in a computable file format. Some electronic health information might not be available in a computable format, such as PDF documents or images. The actual files can be reviewed in the export.

The export file will consist of a compressed (zip) archive with the following information:

Category Description Folder Name File Format
Medical Records Medical records in industry-standard C-CDA format CCDA XML (C-CDA)
X-Rays X-Ray images Xray DCM (DICOM)
Scanned Images Insurance Cards, Photo ID, etc. Scan, with a sub folder per type of document (i.e. InsCard, PhotoID) JPG, PNG, etc.
Consults Documents from referrals ConsultNotes PDF
Messages Secure Messages sent to and from the patient DirectSecureMessages EML (Email File Format)
Forms Various forms, such a Drug Screen results Forms PDF
Financials Billing and Claim information BillingClaim JSON
