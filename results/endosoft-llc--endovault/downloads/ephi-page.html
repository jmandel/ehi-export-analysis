EHI (ePHI) Export

EHI – Electronic protected health information (ePHI) Export functionality allows EndoVault to do an export of health data for one or more patients. EndoVault supports the data export in CCD/C-CDA and ndjson formats. The C-CDA file uses stylesheets which is native to EndoSoft and provides a better user experience in viewing the patient data.

End-user can define what kind of data that they want to export. Below are the available sections that a user can choose.

  • Allergies
  • Encounter
  • Immunizations
  • Medications
  • Plan of treatment
  • Referral reason
  • Active problems
  • Reason for visit
  • Implants
  • Health concerns
  • Procedures
  • Functional status
  • Results
  • Social history
  • Vitals
  • Goals
  • Discharge instructions
  • Assessments
  • Cognitive status
  • Media
  • Diagnostic Report
  • Documents
  • Service Request

EndoVault offers two methods for data export.

  • Single/multi patient export
  • Bulk EHI export

Single/multi patient export

EndoVault uses HL7 C-CDA 2.1 guidelines to export the data. The file name format would be.

File NameDescription
*.xmlDiscrete data elements
CDA.xslStylesheet

EndoVault supports both “All patient information” as well as “Single patient information” data export.

Bulk EHI Export

EndoVault uses FHIR APIs to export the data. More information can be found here.
