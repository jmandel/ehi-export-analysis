Overview
This documentation describes each GEHRIMED EHI table as of 11/06/2023 at 2:00 PM EDT in the
current released version. The documentation reflects the most current information at the time it
was produced. The documentation is broken out by form (where applicable) and then table.
Documentation from a specific organization might differ based on the organization's version of
GEHRIMED, custom development, or definition of EHI data. Each table's file contains a description
and column details. In addition to creating the extracts, the tool will also generate documentation
specific to that organization’s environment.
