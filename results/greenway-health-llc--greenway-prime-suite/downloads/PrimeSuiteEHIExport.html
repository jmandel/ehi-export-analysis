Prime Suite EHI Export

The output of a Prime Suite EHI Export is a package of files containing patient records. The Prime Suite EHI export package will include the below data sets for single patient and patient population export requests. Reference materials are provided to help with the interpretation of this data. Some of the files provided as part of the Prime Suite EHI Export will need to be processed through a conversion tool to be unencrypted. The Prime Suite Conversion Tool installation file is available on the My Greenway support portal. Information about exporting and converting single patient or patient population EHI is provided in the Prime Suite online help.  

The minimum supported version for EHI export is: Prime Suite version 21.23.00.00

Data Dictionary XML Reference

Single Patient Export

The Prime Suite Single Patient EHI Export/Conversion files include all the electronic health information for the specific patient. The EHI Export/Conversion package will contain the following:

  • Tables - The Data files store tables of the patient's data in XML format, including data about documents and images. A reference for these tables is provided in the Data Dictionary.
  • Documents - The Document files include the exported/converted patient documents and images, which may be in any of these formats: PDF, CCDA (xml), TIF, JPG, GIF, BMP, or TXT.

    • These files can be viewed in applications that support the specific format. Each clinical document is accompanied by two xml files, a Data file and a Document file, that provide information about the document, including the related patient ID. The naming convention for the two XML files matches the associated document or image filename and serves to identify the association.

For further details about the structure and schema of the single patient export with conversion, click here.

Patient Population Export

The Prime Suite Patient Population EHI Export package will contain the following:

  • Tables - The Data export will contain multiple XML files, each storing tables of patient data of a specific type. A reference for these tables is provided in the Data Dictionary.
  • Documents - The Document export includes the exported patient documents and images. The exported document XML files in the machine-readable format will have to be processed through a conversion tool to be decrypted to one of these formats: PDF, CCDA (xml), TIF, JPG, GIF, BMP, or TXT. The Prime Suite Conversion Tool installation file is available on the My Greenway support portal.
