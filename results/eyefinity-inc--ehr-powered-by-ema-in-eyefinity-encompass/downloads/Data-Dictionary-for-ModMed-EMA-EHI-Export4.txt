Introduction:
Modernizing Medicine (ModMed) enables Customers in the ambulatory setting to easily export demographic and billing
formation pertaining to patient records, using our Electronic Health Information (EHI) Export capability. The EHI Export
can be exported for a single or for multiple (all) patients.
This Data Dictionary (“dictionary”) is the sole property of Modernizing Medicine, Inc. ("ModMed"). By accessing or using
the dictionary you hereby agree to maintain the dictionary and its contents in confidence and to not share the dictionary
or any of its contents with any third parties without prior written authorization from ModMed. Notwithstanding the
foregoing, nothing herein shall be construed to prohibit or restrict any communication that is protected by 45 C.F.R. §
170.403.
This dictionary describes the tables and columns contained in the ModMed EHI Patient dataset. A few points to note:
● Practice Management (PM) tables and columns are included in the dataset and will be empty for practices not
using PM.
● All date/timestamp fields are recorded using UTC time, unless the field has the "_ld" suffix.
● In fields with the "_ld" suffix" the date/time was converted to local time using the time zone value for the record
(facility or user time zone).
● String type columns with an unrestricted length (equivalent to text and long text types) will have a value of -1 in
the Field Length column of the Data Dictionary sheet.

PM Financials

Financial tables related to Practice Management

Medical Lookup

Static lookup tables for medical content (CC/HPI, Exam, Diagnosis, Procedure, Pathology Log)

Some tables do not track data longitudinally (i.e. change history), this is captured in the "Longitudinal tracking" column.
Y

Longitudinally tracked - new row(s) for each visit (or item), once a visit is finalized cannot be
modified.

N

Not tracked over time, data is the most recent information as of when the data was exported.

L

New entry for each item, but changes to the item are not tracked over time (data is the most
recent information as of when the data was exported).

S

Static lookup table

Export File Formats:
●

Clinical EHI Export data files are machine readable and are made available in pipe-delimited CSV file format with
one file per table for the structured portion. These files are found in the “xxxx_data_extract” folder of the .zip file.

●

Our export also includes, wherever relevant, additional human readable files in XML, JPEG, PNG, TIFF, JSON or
PDF formats, which contain patient health information. Examples include imaging results, scanned clinical
documents, etc. Lab, RX and other attachments are made available in the Attachments folder.
