Electronic Health Information - Export

DigiDMS EHI Export Document
DigiDMS 25.0 is Drummond certified EHR and complying each certification criteria outlined in (b)(10) Electronic Health Information (EHI) Export. As part of EHI Export EHR user can perform data export operation for single as well as bulk patients given the access rights. Authorized user will be able to generate Clinical Care Document for single patient or patient population based on the mode of operation. Exported file format is C-CDA standard and in accordance with the standards specified in HL7 CDA® R2 IG: C-CDA Templates for Clinical Notes R2.1 Companion Guide. EHR user can export EHI without any technical/developer assistance from the EHR
