Electronic Health Information (EHI) Export

CharmHealth EHR supports exporting individual and bulk Patient data in accordance with the 170.315 (b)(10) Electronic Health Information (EHI) export criterion of the ONC 2015 Edition Cures Update Certification.

Practices can export the patient data in FHIR Version 4.0.1, HL7 CCDA, and CSV formats. Refer to the sections below to learn about exporting single patient and bulk patient data from CharmHealth.

Clinical Data Export

CharmHealth API Program offers a comprehensive set of HL7 FHIR (Fast Healthcare Interoperability Resources) APIs that allow practices to export patients' medical records as per the standard FHIR resource specification version 4.0.1.

APIs are available for the FHIR resources below:

  • AllergyIntolerance
  • Appointment
  • CarePlan
  • CareTeam
  • Condition
  • Device
  • DiagnosticReport
  • DocumentReference
  • Encounter
  • FamilyMemberHistory
  • Goal
  • Immunization
  • Location
  • MedicationAdministration
  • MedicationRequest
  • Medication
  • Observation
  • Organization
  • Patient
  • Practitioner
  • Procedure
  • QuestionnaireResponse
  • RelatedPerson

Additionally, you can export the patient records in bulk as New Line Delimited JSON (NDJSON) files using our Bulk Export API.

You can also export the medical records in HL7 CCDA version 2.1 format using our CCDA API and from the respective patient dashboard in CharmHealth EHR.
