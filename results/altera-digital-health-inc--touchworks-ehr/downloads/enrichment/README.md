# Enrichment: TouchWorks EHI Export Table Extraction

## Run Command

```bash
cd /home/jmandel/hobby/ehi-export-analysis/results/altera-digital-health-inc--touchworks-ehr/downloads/enrichment
bun run extract-tables.ts
```

## Input Boundary

Parses all HTML files under `../twehr-2026.1/Touchworks/User_databases/*/Tables/*.html`
(excluding `Tables.html` and `index.html` navigation pages).

Source: TWEHR-2026.1-Touchworks-EHI-Export-Definition.zip, extracted from
https://www.alterahealth.com/download/204/ehi-documentation/16825/twehr-2026-1-touchworks-ehi-export-definition

## Output Files

- **tables.json** — Array of 577 table objects, each with:
  - `database`, `schema`, `tableName`, `fullName`, `description`
  - `columns[]` — name, dataType, maxLengthBytes, nullability, default, description, isPrimaryKey, hasForeignKey, foreignKeyTarget, indexCount
  - `foreignKeys[]` — name, columns, referencedTable
  - `indexes[]` — name, columns, type
  - `sourceFile` — relative path to the source HTML
- **coverage.json** — Parsing statistics: files discovered, parsed, failures, per-database counts, column description coverage

## Known Parsing Limitations

- Foreign key targets extracted from `title` attributes on `<img>` elements; complex multi-column FKs may be partially captured
- Index details may lose some multi-column information in dense HTML
- Column descriptions that contain HTML entities are decoded as plain text
- The parser assumes the HTML structure generated by Altera's documentation tool (consistent across all 577 files in this version)
