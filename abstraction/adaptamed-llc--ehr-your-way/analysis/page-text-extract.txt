Electronic Health Information Export
			

                
170.315(b)(10) ELECTRONIC HEALTH INFORMATION EXPORT

EHRYourWay supports the export of Electronic Health Information (EHI) in compliance with the Office of the National Coordinator for Health IT’s (ONC) certification criterion at 45 CFR 170.315(b)(10).

Supported Export Capabilities

EHRYourWay enables authorized users to export complete electronic health information for single patients, multiple selected patients, or entire patient populations. Users can execute exports at any time without developer assistance.

Export Formats

Exported data is provided in computable, machine-readable formats including CCDA (Consolidated Clinical Document Architecture) XML files based on HL7 CDA Release 2.1 standards, as well as human-readable PDF documents. Exported files are packaged as a ZIP archive containing the CCDA in both readable and XML formats, along with any associated clinical documents and attachments.

Access Controls

The ability to generate EHI exports is limited to users who have been granted export privileges by a practice administrator.

Export Controls

EHRYourWay supports two export workflows: single patient export from within a patient’s chart, and bulk export for multiple patients from the dashboard.

Single Patient Export

Users with export privileges can export a single patient’s EHI by navigating to the patient’s chart, selecting the CCDA folder, and choosing Data Export.

From the Data Export screen, users can select a date range and choose which clinical sections to include in the CCDA. Users can also navigate to the Attachments tab to select scanned clinical and administrative documents to export alongside the CCDA in PDF format.

After making selections, users click the Export button and choose a save location. The exported ZIP file contains the CCDA in both human-readable and XML formats, along with any selected clinical documents as PDFs.

Bulk Export

Users with export privileges can export EHI for multiple patients by navigating to the CCDA Export folder on the Dashboard and selecting Data Export from the dropdown menu.

From this screen, users can filter by date range and provider, then click Go to display matching patients. Users select patients from the list and move them to the export queue using the arrow icon. After selecting all desired patients, users click Next to generate the clinical messages.

Once generation is complete, users can review the exported data in both readable and electronic formats, then click Save & Export File(s) to download. The export produces individual ZIP files for each patient containing CCDA files in readable and XML formats, along with associated PDF documents.

Export Format Specification

EHRYourWay generates CCDA documents based on the HL7 Implementation Guide for CDA Release 2: Consolidated CDA Templates for Clinical Notes, Draft Standard for Trial Use, Release 2.1 (August 2015).
