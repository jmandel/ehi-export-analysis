Data Export
Accessing Data
Data may be accessed once an export is successfully executed under Patient Export section in Practice
management.




File Type Details
The exported data will be present inside a .zip file, which contains multiple files. The main data files will
be available in the format .csv. The first line of a .csv file is the header, separated by comma. Each row
after the first row represents a piece of data related to a patient. Other files, such as images and other
.xml data will be referenced by the .csv files.
