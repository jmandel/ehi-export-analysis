Overview
This documentation describes each TheraOffice Electronic Health Information (EHI) table as of
05/29/2024 at 4:00 PM EDT in the current released version. The documentation reflects the most
current information at the time it was produced. The documentation is broken out by form (where
applicable) and then table. Documentation from a specific organization might differ based on the
organization's version of TheraOffice, custom development, or definition of EHI data. Each table's file
contains a description and column details. In addition to creating the extracts, the tool will also
generate documentation specific to that organization’s environment.

Glossary of Terms
To assist organizations in interpreting the information here, Netsmart is providing a glossary of terms for
those commonly used field descriptions.
 Field Name                        Description
 Id                                The database row id of the selected record. When present, this field
                                   will often be considered a unique row identifier of the database
                                   content.
 Pat_ID                             Pat_ID is the typical method to indicate that unique patient
                                    identifier within the TheraOffice environment.
 MODIFIED_USER                      The user who last updated the row.
 MODIFIED_DATE                      The date the row was last updated.
 CREATED_USER                       The user who created the record.
 CREATED_DATE                       The date the row was created.
