§170.315(b)(10) Electronic Health Information export

Overview
AuroraEHR's EHI Export feature allows privileged users to export a single patient's EHI data. This
functionality simplifies the retrieval of clinical and demographic data housed within the system.
This document serves as a guide for users, providing instructions on performing the export
features and detailing the file structure and formats of the extracted files.


Intended Users
Users who are members of the following User Groups can utilize the EHI Data Export feature:
 Administrator
 Billing Manager
 Clinical Manager
 Front Office Manager


Single Patient Data Export
Data Export creates a zip file containing data for the selected patients and the selected
categories of data. Data will either be in PDF format (for categories with (report) in the title) or
CSV format. The zip file is placed onto the user's desktop.

Access the Data Export screen through AuroraEHR > Data Export.

Patient Population Data Export
AuroraEHR offers the capability to export all data for a patient population. The exported data will
be delivered in a .zip folder, adhering to the same format outlined below. To initiate a patient
population export, please submit a request to gvti@practice-alt.com.


Export Format
Each export results in a single zip file. The name of the zip file is formatted as [user
id]-dataExport-[practice code]-[current date/time formatted as MMddyyyyHHmmss].zip. For
example, an export zip file could be called gvtsstag-dataExport-DEV-11272023114100.zip. The
zip file is organized into sub-folders for each patient account included in the export and that
sub-folder containing the exported data for that patient account. If the Documents/Scans/Reports
export category is chosen, then three additional sub-folders are created for each exported patient
account: Documents, Scans, and Reports. These sub-folders contain the actual document, scan,
or report files. The categories as outlined in the below Supported Categories for Export detail the
specific names of the files/folders created when an export is started. An example export may look
