We are committed to making patient data easily shareable in standardized electronic formats as required
by 170.315 (b)(10). Here is a clear overview of the formats and structures we provide.

    1. Patient’s Clinical Data Via Consolidated Clinical Data Architecture (CCDA) Format

Users have the option to export clinical data for one or multiple patients using the care coordination
feature in blueEHR. They can simply select the specific data they want to export using checkboxes (as
shown in the image).




    2. Demographics, Lab, and Payment data

Users can export single or multiple patients' demographic details, Insurance details, Payments etc. via the
Analytics feature in BlueEHR. Additionally, users can also utilize the Analytics feature to export data
related to lab results, encounters, and appointment details in BlueEHR.

This data can be exported as CSV (Comma Separated Values) or xls format.




    3. Documents

Any documents that are attached to patients' records can also be exported. This can be retrieved from
document module.
