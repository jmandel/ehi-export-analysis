1. Introduction
This document provides information to comply with the Electronic Health Care (EHR)
2015 Edition Cures Update certification criteria 170.315(b)(10) Electronic Health
Information export, and its Information Blocking act.
This document may be found at
http://www.hc2000inc.com/Pages/MDVita_EHR_EHI_DataFormat.pdf
Please, use the MDVita User Guide for instructions how to schedule an EHI export. The
guide can be found in the MDVita application.



2. Data Files
Data files are divided in 3 groups: Raw Data, SOAP Notes, and Documents
Raw Data – These are Parquet data format files
Example of file name: Patient.parquet
For information about the Parquet data format, please visit: Apache Parquet
SOAP Notes – Patients Clinical Notes are exported in pdf format. An index raw data file
is produced matching Notes to Patient “SOAPNotesIndex.parquet”. The SOAP Notes
pdf documents are machine readable. The documents were built programmatically to
produce human readable format.
Documents - Documents are exported in the same original format as they were
uploaded to MDVita (pdf, xml, html, csv, doc, jpg, etc.). An index file is produced
matching documents to Patient “DocumentsIndex.parquet”
SOAP Notes and Documents are provided by reference. A file containing URL
references is created. The URL may be used to download each one of the documents.
The reference files are comma delimited and structured to be machine readable for
automated download of files.
SOAP Notes reference file: SOAPNotesReferences_XXX.csv
Document reference file: DocumentsReference_XXX.csv
XXX – represents a numeric run instance number.
