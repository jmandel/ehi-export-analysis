Column Information
Name Type
1 AU_PRESCRIPTION_CMOP_EVENT_IEN INT
Description: Unique identifier for the AU_PRESCRIPTION_CMOP_EVENT file.
Name Type
2 AU_PRESCRIPTION_IEN INT
Description: FK to AU_PRESCRIPTION
Name Type
3 TRANSMISSION_NUMBER NVARCHAR
Description: This the number of the transmission which contained this prescription.
Name Type
4 SEQUENCE_# DECIMAL
Description: This is the message number of the Rx when it was transmitted to the CMOP.
Name Type
5 RX_INDICATOR DECIMAL
Description: This is the fill number of the Rx. A '0' indicates that it was anoriginal fill.
Name Type
6 STATUS NVARCHAR
Description: The current status of the prescription fill for the Consolidated MailOutpatient Pharmacy. A status of Transmitted means that the Rx has beentransmitted to the CMOP for processing. A status of Dispensed means thatthe Rx has been filled and mailed by the CMOP. A status of Retransmittedmeans that the original transmission with this Rx had to be retransmittedto the CMOP. A status of Not Dispensed means that the vendor system wasnot able to fill the Rx. If the status is Not Dispensed, the reason willbe in the Reason field.
Name Type
7 NDC_RECEIVED NVARCHAR
Description: The National Drug Code (NDC) returned for this prescription.
Name Type
8 CANCELLED_DATE_TIME DATETIME
Description: This is the date and time the Rx was cancelled at the CMOP. If cancelled,the Rx was not filled.
Name Type
9 RESUBMIT_STATUS NVARCHAR
Description: This field is used to track whether this fill has been resubmitted to theCMOP. If the field contains 'yes' then the fill has been resubmitted andcannot be resubmitted again.
Name Type
10 CANCELLED_REASON NVARCHAR
Description: This is the free text reason the Rx was not filled at the CMOP.
Name Type
11 DATE_SHIPPED DATETIME
Description: The date/time the prescription was shipped to the patient from the CMOP.
Name Type
12 CARRIER NVARCHAR
Description: The carrier responsible for shipping the prescription to the patient.
Name Type
13 PACKAGE_ID NVARCHAR
Description: A unique identification code assigned by the non-DHCP system for trackingthe prescription shipment.
Name Type
14 NDC_SENT NVARCHAR
Description: The National Drug Code (NDC) sent for this prescription.
Name Type
15 FDA_MED_GUIDE_FILENAME NVARCHAR
Description: This field contains the filename of the FDA Medication Guide for the drug in this prescription at the time the fill was transmitted to CMOP.
