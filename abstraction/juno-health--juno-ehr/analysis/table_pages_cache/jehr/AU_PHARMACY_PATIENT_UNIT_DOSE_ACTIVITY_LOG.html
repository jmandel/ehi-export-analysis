AU_PHARMACY_PATIENT_UNIT_DOSE_ACTIVITY_LOG
Description: This is a record of the actions that have taken place on the order.Actions include EDIT, RENEWAL and CANCELLATION. Stored with the actionis the date and time the action took place and the user who took theaction. If the action is an edit, the data in the field edited priorto the edit is also stored.
