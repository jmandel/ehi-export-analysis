AU_PHARMACY_PATIENT
Description: This file holds, for each patient, information that is typically ofinterest only to the pharmacy. This should be noted when merging patientrecords and deleting the 'old' record from the patient file. That processdoes not delete the corresponding pharmacy patient file entry. This file is also shared with inpatient pharmacy and promises to become avery central file to the pharmacy.
