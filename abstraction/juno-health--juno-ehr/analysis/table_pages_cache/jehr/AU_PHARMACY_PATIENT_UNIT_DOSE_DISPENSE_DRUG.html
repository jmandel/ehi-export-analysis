AU_PHARMACY_PATIENT_UNIT_DOSE_DISPENSE_DRUG
Description: This contains the dispense drug(s), and the related information, for thisorder. The dispense drug is the actual medication dispense by pharmacy forthe order. Dispense drugs are obtained from the DRUG file (#50).

Primary Key
Column Name Ordinal Position
AU_PHARMACY_PATIENT_UNIT_DOSE_DISPENSE_DRUG_IEN 1

Foreign Key
Column Name Ordinal Position Referenced Table
AU_PHARMACY_PATIENT_UNIT_DOSE_IEN 2 AU_PHARMACY_PATIENT_UNIT_DOSE

Column Information
Name Type
1 AU_PHARMACY_PATIENT_UNIT_DOSE_DISPENSE_DRUG_IEN INT
Description: Unique identifier for the AU_PHARMACY_PATIENT_UNIT_DOSE_DISPENSE_DRUG file.
Name Type
2 AU_PHARMACY_PATIENT_UNIT_DOSE_IEN INT
Description: FK to AU_PHARMACY_PATIENT_UNIT_DOSE
Name Type
3 DISPENSE_DRUG NVARCHAR
Description: This is a medication that will actually be dispensed by pharmacy for thisorder. Each dispense drug of an order must be tied to the primary drugof the order.
Name Type
4 UNITS_PER_DOSE DECIMAL
Description: This is the number of UNITS (tablets, capsules, etc.) to be dispensed as aDOSE for this order. The literals '1/2' and '1/4' may be entered. If thereis no entry, it is assumed to be ONE (1). ** PLEASE NOTE ** If a doctor prescribes 30 ml's of a medication that is usually dispensedand administered as 60 ml's, the correct UNITS PER DOSE would be 1/2 (or.5), NOT 30 ml's. (30 ml's would be entered into the DOSAGE ORDERED field.) If the UNITS PER DOSE ordered is a variable amount (1-2 tab.), it issuggested that the maximum amount be entered into this field and the amountordered noted either in the DOSAGE ORDERED or SPECIAL INSTRUCTIONS fields.
Name Type
5 INACTIVE_DATE DATETIME
Description: This is the date that this dispense drug will no longer be dispensed forthis order. Once an order becomes active, dispense drugs cannot be deleted.
Name Type
6 TOTAL_UNITS_DISPENSED NVARCHAR
Description: This is the total number of units actually dispensed for this order,including any EXTRA UNIT DISPENSED, and PRE-EXCHANGE NEEDS.
Name Type
7 UNITS_CALLED_FOR DECIMAL
Description: This is the total number of units to be dispensed for this medicationas calculated by the package.
Name Type
8 UNITS_ACTUALLY_DISPENSED DECIMAL
Description: This is the number of units of this medication actually dispensed asentered by the pharmacist.
Name Type
9 TOTAL_RETURNS DECIMAL
Description: This is the total number units returned for this medication over thelife of the order.
Name Type
10 RETURNS DECIMAL
Description: This is the number of units returned of this medication from the patient's cassette upon the termination of this order.
Name Type
11 PRE-EXCHANGE_UNITS DECIMAL
Description: This is the number of actual units required for this order until thenext cart exchange.
Name Type
12 TOTAL_EXTRA_UNITS_DISPENSED DECIMAL
Description: This is the total number of extra units dispensed for this order overthe entire life of the order.
Name Type
13 EXTRA_UNITS_DISPENSED DECIMAL
Description: This is the number of units dispensed outside of the normal dispensingprocess (pick list).
Name Type
14 TOTAL_PRE-EXCHANGE_UNITS DECIMAL
Description: This is the total number of pre-exchange units dispensed over the lifeof the order.
