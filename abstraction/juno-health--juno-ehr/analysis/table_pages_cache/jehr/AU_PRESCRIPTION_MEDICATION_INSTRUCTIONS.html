AU_PRESCRIPTION_MEDICATION_INSTRUCTIONS
Description: This sub-file will contain the dispense units per dosage ordered, dosageordered, units, noun, duration and conjunction fields.

Column Name Ordinal Position
AU_PRESCRIPTION_MEDICATION_INSTRUCTIONS_IEN 1

7 DURATION NVARCHAR
Description: This is the length of time that a medication order should be given. If youenter a numeric value, Days will be assumed. You may also enter a numericvalue followed by a letter. The letters can be entered as 'M' for Minutes,'H' for Hours, 'D' for Days, 'W' for Weeks, 'L' for Months. THIS IS NOT DAYS SUPPLY!
Name Type

Name Type
