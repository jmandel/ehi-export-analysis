AU_PRESCRIPTION_RETURN_TO_STOCK_LOG
Description: This sub-file contains a record for each fill returned to stock for the prescription.

Primary Key
Column Name Ordinal Position
AU_PRESCRIPTION_RETURN_TO_STOCK_LOG_IEN 1

Foreign Key
Column Name Ordinal Position Referenced Table
AU_PRESCRIPTION_IEN 2 AU_PRESCRIPTION

Column Information
Name Type

Name Type

Description: FK to AU_PRESCRIPTION
Name Type
3 RETURN_TO_STOCK_DATE_TIME DATETIME
Description: This is the date/time the prescription fill was returned to stock.
Name Type

Description: This is the prescription fill number that was returned to stock (e.g., '0' for the original fill, '1' for refill 1, '2' for refill 2, ...). For partial fills, the letter 'P' is appended to the fill number (e.g., 'P1' for partial fill 1, 'P2',for partial fill 2, ...).
Name Type

Name Type

Name Type
9 MAIL_WINDOW NVARCHAR

Name Type

Name Type

22 PROVIDER NVARCHAR

Name Type
23 ADMINISTERED_IN_CLINIC NVARCHAR

Name Type
33 NDC_VALIDATED_BY NVARCHAR

Name Type
34 BILLING_ELIGIBILITY_INDICATOR NVARCHAR

Name Type
