4 STRENGTH NVARCHAR
Description: 'STRENGTH' is the amount of an additive that is used in the manufacturingof the IV order. NOTE! You'll be expected to use the strength unitsthat have been previously defined within the additive file (52.6) for eachadditive. That is to say, if the additive file expects AMPICILLIN to bedispensed in 'GMS', it would not be correct for you to enter '500' for ahalf-gram dose -- enter 0.5 instead.
Name Type
5 BOTTLE NVARCHAR
Description: This is the bottle number (or numbers, separated by commas) in which this additive will be included for this IV order. If this field is blank, it means that the additive will be included in all bottles.
