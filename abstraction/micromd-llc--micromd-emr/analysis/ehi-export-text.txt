     MicroMD EMR 170.315(b)(10) Electronic Health Information export (EHI)
     This documentation provides information for the format of the export output when utilizing the MicroMD
     EMR EHI export. The intended purpose satisfies the requirements of 2015 Edition Cures Update
     Conformance Regulation §170.315(b)(10) Electronic Health Information export,

     ONC Health IT Certifications
     MicroMD’s EMR 2015 Edition Cures Update Certification Information

     EHI Export File
     A compressed file will be exported when using the EHI process within MicroMD EMR
     (see user manual for instruction). The file will have a naming convention of the
     practice id and the patient chart id (####.######.0). This file will be password
     protected using the patient date of birth (mmddyyyy). The following files with
     schema will be included with this compressed file.
