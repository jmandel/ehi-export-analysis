 ​or using the dictionary you hereby agree to maintain the dictionary and its contents in confidence and to not​

   ​ModMed.​




​Document purpose​
​This dictionary describes the tables and columns contained in the ModMed EHI Single Patient dataset. Refer to​
 ​the training manual for more detailed usage information.​

​When using this data dictionary, please note the following:​
   ​●​ ​Practice Management (PM) tables and columns are included in the dataset and will be empty for​
           ​practices not using PM.​
    ​●​ ​All date/timestamp fields are recorded using UTC time, unless the field has the "_ld" suffix.​
     ​●​ ​In fields with the "_ld" suffix" the date/time was converted to local time using the time zone value for the​
            ​record (facility or user time zone).​
      ​●​ ​String type columns with an unrestricted length (equivalent to text and long text types) will have a value​
             ​of -1 in the Field Length column of the Data Dictionary sheet.​

​Longitudinal Tracking​
 ​Some tables do not track data longitudinally (i.e. change history), this is captured in the "Longitudinal tracking"​
  ​column​

       ​Y​          ​Longitudinally tracked - new row(s) for each visit (or item), once a visit is finalized cannot be modified.​
       ​N​          ​Not tracked over time, data is the most recent information as of when the data was exported.​
                     ​New entry for each item, but changes to the item are not tracked over time (data is the most recent​
