CareTracker EHI Export: Folder Organization and Data Format Specification – v1.0
The EHI Export feature is designed to facilitate efficient data export for both individual patients and patient
populations within a comprehensive healthcare system. This comprehensive functionality caters to two primary
scenarios: exporting data for a single patient or exporting data for a patient population. In the patient population
scenario, users have the flexibility to select patients based on different criteria, such as Provider, All Active
Patients, All Patients, or Patients within an Encounter Range.



In both the single patient and patient population scenarios, a dedicated folder is created for each patient,
marked with a timestamp to facilitate easy identification. The exported data is formatted in a machine-readable
manner to ensure interoperability and ease of data processing.



Inside each patient's folder, a distinct file structure is maintained to accommodate different Data Classes. Each
Data Class corresponds to a specific category of patient information. The corresponding information, such as
Imported Items, images, and related documents, is stored within a designated "Documents" subfolder,
preserving the original storage or import format.



To maintain consistency and clarity, the filenames for each data entry within a Data Class follow a standardized
pattern: "[Data Class Name].[Export Format]". The "[Export Format]" extension indicates the data format for
export, with options including ".csv" (Comma-Separated Values), ".json" (JavaScript Object Notation), and ".xml"
(Extensible Markup Language).
